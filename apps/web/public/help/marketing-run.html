12-week marketing task

One synthetic launch, 12 dependent weekly decisions and a final board memo. Simulated weeks run sequentially; no real advertising or email is sent.

Prepare without spending

  1. Data Engineer → Case bank → Import 12-week marketing task.
  2. Review the exact source rights for local evaluation and OpenAI processing. Calibrate and approve its rubric, then qualify and publish its task.
  3. Researcher → create a suite with this one task and an approved objective; obtain technical review and freeze the suite.
  4. Admin → Providers → configure OpenAI gpt-6-sol with the marketing defaults, after reviewing terms and pricing.
  5. Researcher → Protocols → choose 12-week marketing · OpenAI gpt-6-sol, the exact connection and suite. Review the comparison plan and obtain technical approval.
  6. Select Prepare marketing run. Run console shows progress and missing launch gates.

Key and approvals

Store your key only in the owner-only local file .secrets/openai_api_key. Set OPENAI_API_KEY_FILE=.secrets/openai_api_key in the existing local .env, with OPENAI_API_KEY empty or unset. Restart Anvil. Never paste keys into chat or forms.

Two distinct real Admins must each approve provider activation and the exact paid run. Demo accounts are rejected. Real-person onboarding still requires separate local provisioning; do not relabel demo identities. Launch remains blocked until these gates are satisfied.

Cost and recovery

The cumulative API ceiling is $100. Each run allows at most 13 calls and $13 of conservative reservations. This is separate from the $120,000 simulated campaign budget. Pricing review expires October 5, 2026 at 00:00 UTC.

Reservations remain held until separate billing reconciliation. Unknown dispatches are never automatically retried. Cancel cannot retract an in-flight call. Invalid JSON or actions are retained and end the sequence for review.

The final decision trail enters the existing independent review workflow. Mocked software tests are not model performance.

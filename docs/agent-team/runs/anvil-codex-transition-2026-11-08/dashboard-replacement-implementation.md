# Replacement benchmark dashboard implementation

The replacement follows the confirmed PDF decisions in `benchmark-dashboard-replacement-decisions.md`. The four connected views replace the benchmark landing experience. The earlier illustrative banking preview remains explicitly labeled as a mockup and is not the new results dashboard.

## Implemented source

- Overview and leaderboard read project-scoped stored comparisons. Existing task scores remain separate from judge metrics. Observed win/tie rate and Bradley–Terry are different calculations; disconnected or separated win graphs do not receive an invented finite ranking.
- Reviewed offline-contract task scores remain visible as software evidence, but are excluded from model leaders, model error rates and model rankings. Current source/signer/dependency policy and artifact access are rechecked; revoked observations cannot retain current scored-cell or cost claims.
- Trace and rubric inspection reads authorized captured outputs, deterministic criterion points and observable stored steps. Historical fictional controls remain non-ranking audit facts, with their original receipt digests and source provenance. No hidden reasoning, current qualification or live model performance is inferred.
- Failure analysis separates model criterion/threshold failures, infrastructure failures and intentional negative controls. Priority is rule-derived, not calibrated human-risk severity. Cluster focus narrows inspection and linked curation; cohort rate denominators remain explicit.
- Golden datasets preserve immutable case versions, predecessor bindings and distinct human verification requirements. Persona remediation saves proposals and bounded blocked execution intents. An unavailable compatible executor is reported as a blocker, with zero provider calls and no prompt auto-application.
- Executive and technical PDF exports bind to the selected snapshot. Private inputs, expected answers and proposed prompts are excluded. Stale snapshot, access revocation and changed receipt checks fail closed.
